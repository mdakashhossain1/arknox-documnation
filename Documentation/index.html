Project Overview & Features

Quizs is an advanced, high-performance exam preparation and mock-test platform tailored for competitive aspirants. It combines previous-year question (PYQ) practice with an authentic NTA-style (National Testing Agency) computer-based test (CBT) simulation — providing timed, section-wise repeatable tests, live question palettes, instant scoring, and comprehensive answer explanations.

Developed using the Laravel PHP framework for the backend and Flutter (Dart) for the cross-platform mobile app, Quizs guarantees enterprise security, safeguarding against SQL injection, XSS attacks, and CSRF vulnerabilities, while delivering ultra-smooth 60fps mobile performance.

cPanel Server Deployment (Step-by-Step)

The installation of this script is super easy. Follow these sequential steps to install the backend and connect your database on any cPanel hosting server.

1
Create the MySQL Database in cPanel

1. Log in to your hosting cPanel account.

2. In the search box, type "database" and select "MySQL® Database Wizard".

3. Step 1: Enter your database name (e.g. quizs_db) and click Next Step.

4. Step 2: Create a database user, set a strong password, and click Create User.

5. Step 3: Check the box for ALL PRIVILEGES, then scroll down and click Next Step to finish.

2
Upload and Extract Backend Source Code

1. In cPanel search, type "file" and open File Manager.

2. Navigate into the public_html directory.

3. Compress the folder Quiz Application Admin into a zip file on your computer.

4. Click Upload in File Manager, select the zip file, and wait for the green 100% upload bar.

5. Right-click the uploaded zip file and select Extract.

6. Move all extracted files directly to public_html/ so that your web entry point is located at public_html/public/index.php.

3
Configure `.env` Database Credentials

In File Manager, right-click the .env file, click Edit, and update the database settings with your cPanel values:

.env configuration
APP_NAME="Quizs"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=cpaneluser_quizs_db
DB_USERNAME=cpaneluser_dbuser
DB_PASSWORD=your_strong_password
4
Run Migrations & Seed Default Data

Via cPanel Terminal or SSH, execute:

terminal
php artisan migrate --seed
php artisan storage:link

Local Terminal / CLI Setup (Quick Commands)

System Settings & Offerwall Configuration

Managing SMTP email delivery, Firebase credentials, and the Web Offerwall rewards engine.

1. Web Offerwall (Unity / Tapjoy Rewards Engine)

The application supports Unity Web Offerwall for rewarding players with bonus tokens. Configure these values in your backend .env file:

.env Offerwall Settings
OFFERWALL_ENABLED=true
OFFERWALL_SDK_KEY="your-web-offerwall-sdk-key"
OFFERWALL_PLACEMENT="#WebOfferwall"
OFFERWALL_CALLBACK_SECRET="your-app-specific-callback-secret"
OFFERWALL_CALLBACK_MODE=hmac_sha256

Callback Endpoint: https://yourdomain.com/api/offerwall/callback/unity

The backend automatically verifies each offer callback with HMAC SHA-256 signatures before crediting points to the player's account.

Firebase & Google Sign-In Fix (SHA-1 Setup)

How to register cryptographic SHA-1 fingerprints in Firebase Console to prevent Google Sign-In Error 10.

Why Google Sign-In Fails (Error 10)
When an app is signed with a key whose SHA-1 is not registered in Firebase, Google instantly rejects the OAuth handshake. You must register both the Debug SHA-1 and the Google Play Store Production SHA-1.

1. Get Debug SHA-1

bash / powershell
cd "Quiz Application/android"
./gradlew signingReport

Copy the SHA-1 fingerprint under Variant: debug.

2. Get Google Play Production SHA-1

In Google Play Console, go to Release -> Setup -> App Integrity -> App signing key certificate and copy the SHA-1.

3. Add to Firebase

Go to Firebase Console -> Project Settings -> Your Android Apps -> Add Fingerprint and paste both keys. Download the updated google-services.json and place it in Quiz Application/android/app/google-services.json.
